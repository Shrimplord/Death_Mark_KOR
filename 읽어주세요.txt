                                                                            적용법
=========================================================================

1. 스팀 라이브러리에서 게임의 언어 설정을 English(영어)로 변경합니다.
   스팀 라이브러리에서 Spirit Hunter: Death Mark 우클릭 -> 속성 -> 일반 -> 언어
   기본 설치 설정이 영어이니 언어 설정을 변경하지 않으셨다면 따로 건드리지 않으셔도 됩니다.

2. 게임 설치 폴더를 엽니다.
   스팀 라이브러리에서 Spirit Hunter: Death Mark 우클릭 -> 관리 -> 로컬 파일 보기

3. Death_Mark_KOR_V1.0.zip 파일의 압축을 푼 후 내용물을 모두 게임 설치 폴더에 붙여넣습니다.
   반드시 "모두 덮어쓰기"를 선택해 주세요.
   "건너뛰기"를 누르면 패치가 적용되지 않습니다.
   "적용 예시.png"를 첨부하니 참고해주세요.

4. "패치 적용.exe"를 실행합니다.

5. 게임을 실행합니다.

=========================================================================
                                                                          주의사항
=========================================================================

[실행 파일 수정]
이 패치는 게임 실행 파일(Death Mark.exe)을 수정합니다.
수정 범위는 다음과 같습니다.
   120항목 가량의 텍스트(시스템 안내 문구가 대부분으로, 게임 진행에 영향을 주지 않습니다)
   이름 입력 시 한국어 입력 가능하도록 로직 수정
   영문판 캐릭터 성/이름 순서 변경
원본 실행 파일은 게임 폴더의 bak 폴더에 보관됩니다.
테스트 시 문제는 없었으나 혹시 모를 오류를 방지하고 싶으시다면 원본 실행 파일을 이용해주세요.
원본 파일 이용 시 다음 사항이 영문판 사양으로 적용되나 게임 플레이에는 지장을 주지 않습니다.
   120항목 가량의 시스템 텍스트가 영문으로 표기
   이름 입력 시 한국어 입력 불가
   일부 메뉴에서 캐릭터의 이름이 이름-성 순으로 표기

[보안 관련]
게임 폴더에 파일을 쓰기 위해 관리자 권한이 필요합니다.
"패치 적용.exe"에는 코드 서명이 없어 윈도우가 경고를 띄울 수 있습니다.
"추가 정보" -> "실행"을 눌러 진행해 주세요.

[설치 후 남는 파일]
Death_Mark_KOR 폴더 및 "패치 적용.exe", "적용 예시.png", "읽어주세요.txt", "패치_버전.txt"가 남습니다.
패치 적용을 마치셨다면 지우셔도 됩니다.
단, 패치 재적용이 필요하실 것 같다면 압축 파일 보관을 추천드립니다.

                                                                        되돌리는 법
=========================================================================

스팀 라이브러리에서 Spirit Hunter: Death Mark 우클릭 -> 속성 -> 설치된 파일
-> "게임 파일 무결성 확인"

=========================================================================
                                                                        패치 재적용
=========================================================================

무결성 확인 또는 게임 업데이트 등으로 패치 적용이 해제될 수 있습니다.
이럴 때는 반드시 패치 적용법에 안내한 절차를 다시 시행해주세요.

=========================================================================
                                                                          문제 해결
=========================================================================

[패치 파일이 제대로 복사되지 않았습니다]
압축을 풀 때 덮어쓰기를 건너뛴 경우입니다.
"모두 덮어쓰기"를 선택해 압축을 다시 풀어 주세요.

[패치 파일이 손상됐습니다]
내려받은 압축 파일이 손상된 경우입니다. 다시 받아 주세요.

[Death Mark.exe 가 손상되었습니다]
게임 파일 무결성 확인을 실행한 뒤 다시 시도해 주세요.
무결성 검사 후에도 문제가 반복될 시 게임 업데이트로 패치 적용이 불가한 경우일 수 있으니
아래 메일로 제보해주세요.

[그 밖의 오류]
오류 화면 캡처와 패치_로그.txt를 아래 메일로 제보해 주세요.
